# Kutak Katik 🏍️

Website interaktif untuk layanan informasi, diagnosis, dan penanganan kendala sepeda motor (khususnya seri Vario LED Old 150)
---

## 🚀 Fitur Utama

- **Navbar Interaktif:** Navigasi cepat dilengkapi *hamburger menu* dan pencarian.
- **Hero Section:** Tampilan awal dengan latar belakang dan pesan ajakan (*call to action*).
- **Informasi Spesifikasi & Masalah Khas:** Penjelasan detail mengenai masalah umum motor (CVT gredek, sistem kelistrikan, suspensi).
- **Katalog Kendala:** Daftar kendala interaktif yang dimuat secara dinamis via JavaScript.
- **Peta & Form Kontak:** Lokasi Google Maps terintegrasi (sekitar area UPI Cibiru) dan form pendaftaran/pesan langsung.

---

## 🛠️ Teknologi & Library

- **HTML5 & CSS3** (Flexbox & Responsive Web Design)
- **JavaScript ES6** (DOM Manipulation)
- **Feather Icons** (`unpkg.com/feather-icons`)
- **Google Fonts** (Poppins)
